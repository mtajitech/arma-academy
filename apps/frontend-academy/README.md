# frontend-academy

**Port:** 3100  
**Description:** ARMA Academy Frontend — primary learner portal built with Next.js 14

## Running Locally

```bash
cp .env.example .env
npm install
npm run dev
```

## Building for Production

```bash
npm run build
npm start
```

## Architecture

- Framework: Next.js 14 (App Router)
- Language: TypeScript 5 (strict mode)
- Port: 3100 (hardcoded — never change)
- Output: standalone (optimized for Docker)
